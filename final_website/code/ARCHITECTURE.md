# Architecture

Astro renders the public reading and search experience on a Cloudflare Worker. Workers static assets serve images, the supplied logo derivative, self-hosted Noto script subsets, and CSS. Ordinary articles and search work without JavaScript. Client scripts handle only menu enhancements, link copying, the packet illustration, update checks, and opt-in video.

D1 holds canonical identities and immutable revision keys for localized versions. Drizzle reads eligible editions. Writes that combine a publication transition, audit row, and version updates use D1 batches. D1 triggers update locale counters on changes visible to the public. The Worker uses the canonical HTTPS origin and a combined content version in its anonymous edge-cache key. It bypasses the cache when cookies or query parameters are present. Private routes and cookie-bearing responses use `private, no-store`. Conditional checks expose a single locale cursor using ETag.

Keyword search uses NFKC, lowercase, Unicode punctuation and whitespace normalization, and bounded substring matching against indexed locale/state selections. It does not perform morphological search or Indic stemming. Alternative language results preserve their own language and link to their stable content ID. Arabic-script Kashmiri, Sindhi, and Urdu use RTL. Manipuri uses Meetei Mayek. The registry records the reviewed scope of script variants as technical support only.

Better Auth uses the native D1 adapter with Google as the only social provider. The Worker resolves editorial permissions against a separate role table on each protected request. Administrator provisioning requires a controlled database action using the exact authenticated user ID. The local fixture identity only exists in Astro development on loopback after opt-in.

Fixture jobs persist a discovery, evidence, draft, validation, translation, review, and publication sequence. The scheduler can retrieve bounded RSS extracts from approved institutional hosts, reject redirects, deduplicate candidates, and draft with OpenAI. It never treats the feed excerpt as independent corroboration. Live provider drafts always require editorial review. The automatic eligibility rule only covers the built-in educational fixture. A lease token guards stage writes and limits overlap, and expired jobs can resume. Paid calls are reserved in SQL against per-day caps before dispatch. A process failure after a provider request can lead to another separately reserved request on retry. Reservation is an estimate and leaves a usage row even when the request fails.

Sources and content are treated as data. Articles render plain text and application-owned HTML. Provider calls use bounded input, response size, output tokens and timeouts. The site has no user upload route.
